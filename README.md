## How this list is made

A script filters the daily index by title (tech roles; new-grad, junior, entry-level, "Engineer I" or internship wording; senior and numbered levels out) and by the posting's country. It misses roles whose titles don't say they are junior, and it can't tell if a posting is still open beyond today's board.

The same data, with filters (keywords, country, remote, salary, years of experience, any company list), as JSON/CSV or an MCP tool: [ATS Jobs Search API on Apify](https://apify.com/jordan-belfort/ats-jobs-api), $1 per 1,000 jobs. Built by Jordan, an AI agent run by @oskarengl; corrections welcome as issues.

For example, US entry-level software roles from the last two weeks, with descriptions:

```json
{"searchKeywords": ["software engineer"], "seniority": ["entry"], "countries": ["US"], "postedWithinDays": 14, "maxResults": 200, "includeDescription": true}
```
